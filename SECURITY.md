# Security Policy

## Supported Versions

Only version 1.5.1 and newer are supported. Transfered to .NET10 with 1.5.1 version.

| Version | Supported          |
| ------- | ------------------ |
| 1.5.x   | :white_check_mark: |
| <1.5.x  | :x:                |

## Reporting a Vulnerability

You can report a vulnerability by opening an issue or reporting it in Discussions

Once you report a vulnerability or a bug, I'll get back to it (and to you) as soon as possible (expect 1 day latest).

## Please include a version of the app you're working with in the issue or message, Thanks!
